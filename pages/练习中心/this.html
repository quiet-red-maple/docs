JavaScript this 关键字详解

理解 JavaScript 中动态绑定的核心机制

什么是 this?

this 是 JavaScript 中的一个特殊关键字，它在函数执行时被自动设置，指向一个特定的对象。

this 的核心特性

  • this 的值在函数调用时确定，而不是在函数定义时
  • this 不能在执行期间被赋值
  • this 的指向取决于函数的调用方式
function showThis() {
  console.log(this);
}

showThis(); // 在浏览器中输出: Window 对象
记忆要点： this 的指向取决于函数的调用方式，而不是定义位置。

this 的常见场景

1. 默认绑定

独立函数调用时，this 指向全局对象（严格模式下为 undefined）

function normalFunc() {
  console.log(this); // Window (非严格模式)
}
normalFunc();

function strictFunc() {
  'use strict';
  console.log(this); // undefined
}
strictFunc();

2. 隐式绑定

作为对象方法调用时， const obj = {
  name: '对象',
  showThis: function() {
    console.log(this.name);
  }
};

obj.showThis(); // 输出: '对象'

注意： 隐式绑定容易在回调函数和事件处理中丢失。

更多绑定场景

3. 显式绑定

使用 call、apply、bind 方法强制指定 this 的指向

function greet() {
  console.log('Hello, ' + this.name);
}

const person = { name: 'Alice' };

greet.call(person); // Hello, Alice
greet.apply(person); // Hello, Alice

const boundGreet = greet.bind(person);
boundGreet(); // Hello, Alice

4. new 绑定

使用 new 操作符调用构造函数时，this 指向新创建的对象

function Person(name) {
  this.name = name;
}

const alice = new Person('Alice');
console.log(alice.name); // 'Alice'

5. 箭头函数

箭头函数没有自己的 this，它继承自外层作用域

const obj = {
  name: '对象',
  regularFunc: function() {
    console.log('普通函数: ', this.name);
    
    const arrowFunc = () => {
      console.log('箭头函数: ', this.name);
    };
      arrowFunc();
  }
};

obj.regularFunc();
// 输出: 普通函数: 对象
// 输出: 箭头函数: 对象

this 绑定优先级

当多种规则同时适用时，JavaScript 按照以下优先级确定 this 的指向：

绑定类型 描述 示例
new 绑定 使用 new 调用构造函数 new Person()
显式绑定 使用 call、apply、bind func.call(obj)
隐式绑定 作为对象方法调用 obj.method()
默认绑定 独立函数调用 func()
箭头函数例外： 箭头函数的 this 在定义时确定，不受这些规则影响。

常见陷阱与解决方案

陷阱1：回调函数中的 this 丢失

const obj = {
  name: '对象',
  names: ['Alice', 'Bob'],
  logNames: function() {
    this.names.forEach(function(name) {
      console.log(this.name + ': ' + name);
      // 错误: this.name 是 undefined
    });
  }
};

解决方案：

// 方案1: 使用箭头函数
logNamesArrow: function() {
  this.names.forEach(name => {
    console.log(this.name + ': ' + name);
  });
}

// 方案2: 保存 this 引用
logNamesSaved: function() {
  const self = this;
  this.names.forEach(function(name) {
    console.log(self.name + ': ' + name);
  });
}

// 方案3: 使用 bind
logNamesBind: function() {
  this.names.forEach(function(name) {
    console.log(this.name + ': ' + name);
  }.bind(this));
}

陷阱2：方法赋值给变量

const obj = {
  name: '对象',
  getName: function() {
    return this.name;
  }
};

const getName = obj.getName;
console.log(getName()); // undefined (非严格模式) 或 错误 (严格模式)

解决方案：

// 使用 bind 固定 this
const getNameBound = obj.getName.bind(obj);
console.log(getNameBound()); // '对象'
